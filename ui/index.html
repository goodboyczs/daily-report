关于

Daily Report Generator - 自动日报生成工具

📋 Daily Report Generator

一个轻量级的 Node.js 脚本，用于从 Git 仓库自动生成团队日报。

✨ 主要功能

  • ✅ 多仓库支持 - 监听多个 Git 仓库
  • ✅ 多分支支持 - 同名仓库的不同分支可独立配置
  • ✅ 自动聚合 - 同一任务 ID 的提交自动合并
  • ✅ 灵活过滤 - 按 author email、commit message pattern 过滤
  • ✅ 零依赖 - 原生 Node.js，无外部包依赖

📁 目录结构

daily-report/
├── ui/                    # 🌐 Web UI 界面
│   ├── index.html
│   └── assets/
├── scripts/               # 🔧 核心脚本
│   ├── update.js
│   ├── init.js
│   └── add.js
├── config/                # ⚙️ 配置文件
│   ├── config.json        # 必须编辑
│   └── config.example.json
├── data/                  # 📊 生成的报告
│   └── reports.md
├── utils/                 # 🛠 工具库
└── docs/                  # 📚 文档

🚀 快速开始

  1. 编辑 config/config.json 填写作者邮箱和仓库配置
  2. 点击仪表盘的"更新今日日报"生成日报
  3. 查看 data/reports.md 查看生成结果

📧 支持信息

遇到问题? 检查以下几点:

  • 邮箱是否与 git config user.email 一致?
  • 仓库路径是否存在且包含 .git 文件夹?
  • Commit message 是否以 feat: 或 bugfix: 开头?
